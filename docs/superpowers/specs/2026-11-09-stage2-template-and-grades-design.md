# 段階2 設計：曜日テンプレート時間割 ＋ 定期テスト成績管理

段階1（時間割・マスタ・デモ）の上に、2つの機能を足す。データはすべて架空。

## 1. 曜日テンプレート時間割

### なぜ
通常期の時間割は、月〜金で毎週ほぼ同じになる。今の現場では、Excelの「いつもの曜日の表」を開き、その日の変更（欠席・振替・先生の休み）だけを直してから、印刷して教室に貼り出している。アプリでも同じ流れにする。

### 決まっていること（久保さん）
- テンプレートは曜日ごとに作る（月〜金）。
- 日付を開くと、その曜日のテンプレートどおりの時間割が最初から並ぶ。
- その日に加えた変更は、その日だけに効く。翌週の同じ曜日は、テンプレートどおりに戻る。
- 毎週の並びそのものを変えたいときは、テンプレート画面で直す。

### 振る舞い（Claudeの判断）
- **テンプレート画面** `/templates`
  - 曜日タブ（月〜金）と、今の時間割と同じ表（コマ×先生）を持つ。
  - 左の一覧には、その曜日に通う生徒（生徒マスタの通常の曜日・科目）が並ぶ。そこからドラッグで配置する。
  - 配置の警告は、今の時間割と同じ：4人を超えたら赤、担当外は ⚠、同じコマへの二重配置は拒否。
- **日付への反映**
  - 通常期の日付を開いた時点で、その日の配置がまだ1件もなければ、その曜日のテンプレートを実際の配置としてコピーする。
  - コピーで除外するもの：その日に「来られない」となっている生徒・先生の行。先生マスタでその曜日に来ない先生の行も除外する。
  - 一度でもその日の配置があれば、コピーしない。コピーした後に全部を一覧へ戻しても、再コピーはしない（下の「その日の状態」で管理する）。
  - 講習期間の日付には反映しない。講習は申込コマ数で組むため。
- **その日の状態**
  - 日付ごとに「テンプレートから作成済み」を記録し、二重コピーを防ぐ。
  - 時間割画面に「テンプレートに戻す」ボタンを置く。押すとその日の配置を消して、作り直す（確認ダイアログあり）。
- **印刷**
  - 時間割画面に「印刷」ボタンを置く。表だけをA4横1枚に収める印刷用の見た目にする（左の一覧やメニューは隠す）。

## 2. 定期テストの成績管理

### なぜ
保護者面談の資料（前回との比較表やグラフ）を作る手間を減らす。点数はあとで、答案用紙の画像から読み取る機能（段階3：AI-OCR）でも入力できるようにする。

### 決まっていること（久保さん）
- 中間・期末の科目別の点数を扱う。科目は9教科まで。
- 前回との比較表とグラフを出し、面談資料として使える形にする。

### 振る舞い（Claudeの判断）
- **テスト**
  - 年度、学期（1〜3）、種別（中間・期末）、名前（例：2026年度 1学期 期末）を持つ。テストの一覧・追加・削除ができる。
- **点数入力** `/tests/[id]`
  - 縦に生徒、横に9教科の表に、まとめて入力する。
  - 欄を離れたら保存する。入力できるのは空欄か0〜100の整数。
  - 学年で絞り込める。
- **生徒の成績ページ** `/students/[id]/grades`（面談資料）
  - テストごとの点数表（9教科と合計）。
  - 前回テストからの増減を ↑/↓ で表示する。前回は、同じ生徒で点数の入っている直前のテストとする。
  - 合計点の推移グラフ（折れ線）と、科目別の推移グラフ（科目を選んで表示）。
  - 「印刷」ボタンで、A4縦1枚の面談用レイアウトにする。
- **集計**
  - 点数入力画面の下に、テストごとの科目別の平均点を表示する。
  - 順位はこの段階では作らない。
- **合計・平均**
  - 入力された科目だけで計算する。空欄は0点として扱わない。
- **デモデータ**
  - `reset_demo()` に、テスト4回（前年度の3学期期末〜今年度の2学期中間など）と、全生徒分の点数を加える。点数は生徒ごとに少しずつ上下させ、比較やグラフが意味を持つようにする。
  - 曜日テンプレートも、生徒の通常の曜日・科目から作っておく。

## 作らないもの
- 順位表
- 苦手科目から講習を提案する機能
- 内申点・模試
- 職員ログインとゲストの分離（実データを入れる段階で行う）

## 技術
- 段階1と同じ構成：Next.js、Supabase、dnd-kit、Vitest。
- グラフは recharts を使う。
- 業務ルールは `src/domain/` に純粋関数として置き、テスト駆動で作る。対象は、テンプレートのコピー対象の判定、前回比較、合計・平均。
- DBの変更は `0003_*.sql` にまとめ、久保さんが SQL Editor で実行する。

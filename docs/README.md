# ドキュメント一覧

個人塾 時間割・成績管理アプリ（以下「本アプリ」）の設計・開発・運用ドキュメントです。

| No | ドキュメント | 内容 | 主な読者 |
|---|---|---|---|
| 01 | [ローカル環境構築書](01_ローカル環境構築書.md) | 開発用PCに必要なソフト・アカウント・環境変数・DBの準備 | 初めて開発に参加する人 |
| 02 | [ローカル起動手順書](02_ローカル起動手順書.md) | 毎日の起動・停止・テスト・よくあるエラー | 開発者 |
| 03 | [基本設計書](03_基本設計書.md) | 目的・業務・機能一覧・画面一覧・システム構成・非機能要件 | 全員 |
| 04 | [詳細設計書](04_詳細設計書.md) | 画面ごとの動き・業務ルール・処理の流れ | 開発者 |
| 05 | [テーブル定義書](05_テーブル定義書.md) | 全テーブルの列・制約・ER図・DB関数 | 開発者 |
| 06 | [CRUD表](06_CRUD表.md) | 画面・APIごとに、どのテーブルを作成／参照／更新／削除するか | 開発者・レビュー担当 |
| 07 | [API仕様書](07_API仕様書.md) | サーバーAPI（リセット・AI・志望校）の入出力 | 開発者 |
| 08 | [運用手順書](08_運用手順書.md) | ブランチ運用・CI/CD・本番反映・DB変更・デモデータ・AI費用 | 運用担当 |
| 09 | [テスト仕様書](09_テスト仕様書.md) | テスト方針・自動テスト一覧・手動確認項目 | 開発者・レビュー担当 |

そのほかの資料
- [`superpowers/specs/`](superpowers/specs/)：段階ごとの要件・設計メモ（作成時の議論の記録）
- [`superpowers/plans/`](superpowers/plans/)：段階ごとの実装計画

> データはすべて架空です。実在の生徒・答案などの個人情報は扱いません。

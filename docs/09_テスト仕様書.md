# 09 テスト仕様書

## 1. テスト方針

| 種類 | 対象 | 方法 | 実行タイミング |
|---|---|---|---|
| 単体テスト（自動） | 業務ルール（`src/domain/`）とDB行の変換（`src/lib/repo.ts`） | Vitest。**テストを先に書いて失敗を確認してから実装**（TDD） | 手元・CI（push のたび） |
| 型チェック（自動） | 全ソース | `tsc --noEmit` | 手元・CI |
| ビルド（自動） | 全画面・API | `next build` | 手元・CI |
| 結合確認（DB） | 同時実行で壊れやすいDB関数 | Node スクリプトで本物のDBに対して実行 | DB関数を変えたとき |
| 画面確認（手動・ブラウザ） | 画面の操作・表示 | ブラウザ（1920×1080）で操作 | 機能を追加・変更したとき |
| 全体レビュー | 段階ごとの全変更 | 別のレビュー担当（AI）がコード全体を読み、指摘を重要度で分類 | 段階の終わり |

業務ルールを画面やDBから切り離して純粋な関数にしているので、ルールの大部分は自動テストで守られています。

## 4. 画面確認（手動）チェックリスト

画面サイズ 1920×1080、ゲストでログインして確認します。

### 時間割
- [ ] 科目が1つの生徒をマスにドラッグすると配置される。2科目以上なら科目選択が出る
- [ ] 1人の先生のマスに5人入れると赤くなり、1人移動すると戻る
- [ ] 担当外の科目・学年の生徒に ⚠ が付く
- [ ] 同じコマに同じ生徒を置こうとすると「この生徒は同じコマに配置済みです」
- [ ] マスから左の一覧に戻すと配置が消える
- [ ] 講習：配置で残りコマが1減り、移動では変わらず、一覧に戻すと1増える
- [ ] 緊急の曜日変更で、チェックした生徒が一覧に追加される
- [ ] 通常期の未反映の日を開くと、曜日テンプレートが並ぶ。全員を一覧に戻して開き直しても再反映されない
- [ ] 「テンプレートに戻す」で配置と島が元に戻る
- [ ] 同じコマで2人の先生が同じ島を選ぶと両方に「⚠ 島が重複」
- [ ] 日付を素早く切り替えても、表示が前の日付に戻らない
- [ ] 印刷プレビューで、表だけが A4横に収まる

### 授業記録
- [ ] 配置済みのチップをクリックすると授業記録が開く（ドラッグは今まで通り動く）
- [ ] 教材・範囲・理解度・宿題・申し送りを保存すると、チップに 📝 が付く
- [ ] 翌週の同じ生徒・同じ科目を開くと、右側に前回の記録（申し送り）が出る
- [ ] 生徒一覧の「カルテ」で記録が新しい順に並び、科目で絞り込める

### テンプレート・マスタ
- [ ] 曜日タブを切り替え、ドラッグで配置・移動・一覧へ戻すができる
- [ ] 各マスタの追加・編集・削除ができ、再読み込みしても残る
- [ ] 生徒の在籍／卒業タブ、学年・学校の絞り込み
- [ ] 学校の「学年・科目・教材」で学年タブと教材の追加・削除

### 成績
- [ ] 点数入力で 101・-1・7.5・文字が保存されず元に戻る。空欄にすると合計から外れる
- [ ] 学年・学校で絞り込むと平均点も変わる
- [ ] 面談資料で前回比 ↑↓、5教科合計と科目別の推移グラフ、A4縦の印刷

### AI（費用がかかるので必要なときだけ）
- [ ] 教材の目次をチェックし、種類・問題数・難易度を選んで疑似テストを作成できる。解答の表示・印刷
- [ ] 志望校：「現在地を取得」→ 県＋隣県が表示 →「この地域の学校を登録」で件数が表示される
- [ ] 志望校：現在地を取得後、「近い順」で現在地の県 → 隣県の順に並び、地域に「現在地＋隣県」と（現在地）（隣県）の表示が出る
- [ ] 志望校：「AIで調べる」で6項目と出典が入る。手で直して保存できる

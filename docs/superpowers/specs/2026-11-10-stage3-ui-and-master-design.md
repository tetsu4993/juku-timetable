# 段階3 設計：見た目の刷新・マスタ整理・学年繰り上げ・学校・島

段階1・2のアプリへの改善。データはすべて架空。AI-OCR は費用がかかるため見送る。

## 決まっていること（久保さん）
1. 見た目を少しスタイリッシュにする。
2. メニューバーを左側に縦に並べる。
3. マスタはひとつにまとめる。
4. 4月になったら学年が上がる仕組みを入れる。
   - 中3は高1として残す。
   - 辞めた生徒は、これまでどおりマスタから削除する。
5. 生徒の学校がわかるようにする。
   - 生徒の横に表示して見分けられるようにする。
   - 学校ごとの絞り込みにも使う。
6. 時間割のマスで、場所（島）を選べるようにする。島はコマごとに変わる。

## 振る舞い（Claudeの判断）

### 見た目・メニュー
- **左サイドバー**（幅 約220px、濃い紺系）
  - 上にアプリ名を置く。
  - 「時間割」「テンプレート」「成績」と、折りたためる「マスタ」グループ（生徒・先生・学校・島・コマ・期間・講習）を並べる。
  - 下に「デモデータを初期状態に戻す」を置く。
  - 今いる画面を強調表示する。
  - スマホ幅では、上のハンバーガーボタンで開閉する。
- **全体の見た目**
  - 背景は薄いグレー。内容は白いカード（角丸・薄い影）に載せる。
  - アクセント色は1色（インディゴ系）。
  - フォントは Noto Sans JP。
  - 見出しやボタンの大きさをそろえる。
  - 表は、ヘッダーを固定し、行にホバー色を付ける。
- **時間割のチップ**：学年で色分けする（小・中・高）。⚠ と赤いマスは今のまま。
- 印刷用の見た目は今のまま維持する。

### マスタのまとめ
- URLは今のまま（`/students` など）。メニュー上でだけ「マスタ」にまとめる。
- 学校・島は、新しいマスタ画面として追加する。

### 学年の繰り上げ
- 生徒画面の上部に、「{年度}年度の学年に更新」ボタンを出す。
  - 出す条件：今日の年度（4月始まり）が、最後に繰り上げた年度より新しいとき。
- 押すと確認ダイアログを出し、全生徒の学年を1つ上げる。
  - 小6→中1、中3→高1、高3→「卒業」。
  - DB側の関数で、1回のトランザクションとして行う。
  - 実行した年度を記録し、二重に繰り上がらないようにする。
- 「卒業」の生徒の扱い
  - 生徒一覧には残し、「卒業」タブで絞り込めるようにする。
  - 時間割・テンプレートの一覧には出さない。
  - 削除は手動で行う。
- 学年の型に「卒業」を加える。

### 学校
- 学校マスタ：名前と種別（小・中・高）。
- 生徒に学校を1つ設定できる（任意）。
- 表示：時間割のチップ・生徒一覧・点数入力・面談資料に、学校名を小さく出す。
- 絞り込み：生徒一覧・点数入力・平均点で、学年に加えて学校でも絞り込める。

### 島（場所）
- 島マスタ：名前と並び順（例：A島、B島、窓側）。
- 時間割の各マス（その日・コマ・先生）に、島の選択欄を置く。
  - 未選択も可。
  - 配置が0人のマスでも選べる。
- 曜日テンプレートの各マスでも島を設定できる。
  - テンプレートを日付に反映するとき、島も一緒にコピーする。
  - 「テンプレートに戻す」でも同じ。
- 同じ日・同じコマで、複数の先生が同じ島を選んだら、そのマスに注意（⚠ 島が重複）を出す。保存は止めない。
- 印刷では、先生名の下に島名を出す。

### デモデータ
- 学校を4校程度入れ、各生徒に割り当てる。
- 島を5つ入れる。テンプレートの各マスに島を割り当てる。

## 作らないもの
- AI-OCR
- 学校ごとのテスト日程・範囲の管理
- 卒業生の自動削除
- 職員ログインとゲストの分離

## 技術
- 今の構成に追加する。
- 判定ロジックは `src/domain/` に純粋関数として置き、TDDで作る。対象は、学年の繰り上げ、島の重複、絞り込み。
- DBの変更はマイグレーションで行い、Claude が CLI で反映する。
